Marker	Purpose	Programmatic use	Frontend
{{...}}	Verbatim quote	verbatim_percent	Blockquote
[[...]]	Citation	citation_accuracy	Clickable link
>>...<<	Key requirement	requirements[]	Checklist
~~...~~	Warning	warnings[]	Red callout
??...??	Uncertainty	cap confidence at 60	Grey italic
^^...^^	Definition / term	definitions{}	Tooltip on hover
!!...!!	Penalty / fine info	penalties[]	Orange callout
##...##	Section heading	structure the answer	Heading render
++...++	Applies to (scope)	applicability[]	Scope badge
--...--	Exception / exemption	exceptions[]	Indented note



Which ones actually matter for your use case
Must have:

{{}} — core to your scoring system
[[]] — citations are already in your current output
>><< — actionable requirements are what managers need most
~~ — warnings are high value for compliance
Nice to have:

!! — penalties are very useful for managers to understand stakes
-- — exceptions prevent misapplication of rules
^^ — definitions help non-expert users
Optional / later:

++ — scope/applicability (useful but LLM may over-apply)
## — only needed if answers get long and need navigation
?? — uncertainty flagging is good but LLMs rarely self-flag unless prompted hard
